## 📋 Project Overview

SmartWard360 is a unified web-based platform that transforms hospital ward operations from reactive and fragmented to proactive and AI-driven. It eliminates silos, automates documentation, and enhances patient safety through 9 integrated core modules.

### 🚀 Key Features

🤖 **AI Clinical Notes** Generate professional SOAP notes and discharge summaries instantly using AI.

💊 **Rx Safety Checker** Real-time drug-to-drug interaction detection for patient safety.

⇄ **Digital Handover** Structured protocols to eliminate shift-change miscommunication.

🚑 **Ambulance Sync** Pre-hospital coordination with live GPS and ECG data.

🆔 **Universal ID** Seamless patient records integrated via National ID.

## 💻 Getting Started

The project is divided into a **Frontend** and **Backend**. Follow these steps to get it running locally:

### 1. Clone the Repository

```bash
git clone https://github.com/LevitanX1178/SMartWord360.git
cd SMartWord360

```

### 2. Setup Backend

```bash
cd Backend
npm install
npm start

```

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev

```
